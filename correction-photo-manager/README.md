# NAOSU｜是正写真管理

建設現場の「是正前 → 是正後 → 完了保管」を、スマートフォン・タブレット・PCで管理するローカルファーストWebアプリです。

## 主な機能

- 是正前写真・工事名・場所・工種・指摘内容・期限を登録
- 複数写真の一括登録（写真1枚を是正1件として作成）
- 是正後写真と対応内容を追記し、確認待ちへ移行
- 完了時に「対応中」から消し、別の完了保管領域へ移動
- 完了データの検索・復元・完全削除
- 選択した完了データを、写真・管理情報・CSV入りZIPで外部保管
- 添付の「写真4枚帳票.xlsx」に合わせた4枚帳票の印刷／PDF保存
- 端末向け写真圧縮、保存容量表示、永続ストレージ要求
- PWA対応（対応ブラウザではホーム画面へ追加・オフライン利用可能）

## データの保存場所

写真と管理情報はブラウザの IndexedDB に保存されます。GitHubや外部サーバーへ写真を送信しません。

- 対応中：`activeCorrections`
- 完了保管：`completedCorrections`

完了操作は2領域をまたぐ1回のトランザクションで行うため、完了保管に保存できた場合だけ対応中から削除されます。

> ブラウザデータの削除、端末故障、端末交換に備え、完了保管庫から定期的にZIP保管してください。

## 起動方法

ES Modules と Service Worker を使うため、ローカルサーバーまたはGitHub Pagesで開きます。

```bash
cd correction-photo-manager
python3 -m http.server 8080
# http://localhost:8080
```

追加パッケージやビルドは不要です。

## 推奨環境

- iPhone / iPad: Safari 最新版
- Android: Chrome 最新版
- Windows: Edge / Chrome 最新版

HEICの読込み可否は端末・ブラウザに依存します。読めない場合はJPGまたはPNGへ変換してください。

## 運用上の注意

この版は1端末内で完結する構成です。複数人・複数端末で同じデータをリアルタイム共有する場合は、SharePoint / Dataverse / Box等の認証付き保存先を追加してください。公開GitHubリポジトリを写真置場には使用しないでください。
