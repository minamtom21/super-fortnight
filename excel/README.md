# 工事工程表アプリ (Excel版)

`工事工程表アプリ.xlsx` — 工程マスタ1か所への入力で、全体工程表(月単位)・月間工程表(日単位)・日割り工程表(14日間詳細)が数式で自動連動するワークブック。

## シート構成

| シート | 役割 |
|---|---|
| 使い方 | 操作説明・凡例 |
| 設定 | 工事名・工期・表示開始月・祝日リスト・工種リスト |
| 工程マスタ | **作業の入力はここだけ**(最大150行)。工種/作業名/担当業者/開始日/終了日/進捗率/MS(マイルストーン) |
| 全体工程表 | 月単位ガント24か月+赤▼マイルストーン+予定出来高曲線(S字カーブ)+グラフ。自動生成 |
| 月間工程表 | 対象年・月を選ぶと該当月の作業を自動抽出し日単位ガント表示。土日祝を自動色分け |
| 日割り工程表 | 基準日から14日間の日別工程+日別稼働作業数 |

## 仕様メモ

- バー表示は条件付き書式(水色=予定、濃青=進捗率に応じた実績)
- 作業の自動抽出は従来型配列数式 `SMALL(IF(...))`(Excel/LibreOffice両対応)
- マイルストーンは開始日=終了日+MS列「○」で赤▼表示
- 祝日判定は「設定」シートの祝日リスト(編集可)を参照

## 再生成

```bash
pip install openpyxl
python generate_workbook.py   # 工事工程表アプリ.xlsx を出力
```

数式はキャッシュ値なしで書き込まれるため、生成後はExcel/LibreOfficeで一度開いて再計算保存すること(リポジトリ格納版は再計算済み)。
