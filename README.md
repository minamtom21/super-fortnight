# PowerUps｜杭工事管理システム

建設現場の杭工事を管理するための社内向けWebアプリケーション。
業界標準の運用フロー（案件 → 杭情報 → 施工記録 → 帳票）に沿った構成です。

## 機能

- **ダッシュボード** — 案件数・杭本数・進捗率・許容超過件数を一覧
- **案件管理** — 現場名／施主／元請／工法／工期／現場代理人の登録
- **杭情報管理** — 杭No.／杭種／杭径／杭長／設計支持層深度／杭芯座標(X/Y)
- **施工記録入力** — 削孔深度／根固め深度／杭芯ズレ／鉛直度／電流値／セメントミルク量／杭頭レベル／天候／担当者
- **杭芯ズレ自動計算** — ΔX/ΔYから合成ズレを算出、許容値(100mm)超過を自動アラート
- **杭芯配置図** — Canvasによる2D配置図、状態別色分け、クリックで杭詳細へ遷移
- **帳票出力** — 杭一覧CSV／施工記録CSV／印刷プレビュー（杭施工管理表）
- **データ永続化** — localStorageに保存（端末単位）／JSONバックアップ出力

| 杭種 | 工法 |
|---|---|
| PHC杭 / 鋼管杭 / SC杭 / 場所打ちコンクリート杭 / 節杭 / 鋼管ソイルセメント杭 / 既製コンクリート杭 | セメントミルク（プレボーリング）／中堀り／打撃／アースドリル／リバース／オールケーシング／鋼管ソイルセメント |

## 起動方法

依存ゼロの静的SPAです。

```bash
# ブラウザで直接開く
xdg-open index.html   # or: open index.html

# または簡易サーバー経由
python3 -m http.server 8000
# → http://localhost:8000
```

初回アクセス時は「設定」→「サンプルデータを投入」で動作確認用データを入れられます。

## ファイル構成

```
index.html   レイアウト（topbar / sidebar / main）
styles.css   デザイントークン・コンポーネント・印刷スタイル
app.js       ハッシュルーティング・Store(localStorage)・各画面ビュー
```

## 運用フロー

```
案件登録 ──→ 杭情報登録 ──→ 施工記録入力 ──→ 杭芯ズレ確認 ──→ 帳票出力
   ↓                                              ↓
案件編集                                      配置図ビジュアル化
```
