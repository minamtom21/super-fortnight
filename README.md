# 杭州ガイド (Hangzhou Travel Guide)

中国・浙江省の古都「杭州」を紹介する静的Webアプリ。

## 構成

- `index.html` — トップページ（観光地・グルメ・龍井茶・アクセス）
- `styles.css` — 和漢折衷のデザイン（西湖の翠色・朱色・米色を基調）
- `script.js` — 観光地カードの動的描画とカテゴリーフィルター

## 機能

- ヒーローセクション「西湖に映る、千年の詩情」
- 観光地カード（全12スポット）をカテゴリー別フィルタで切替（西湖／寺院・塔／街並み／自然）
- 杭州グルメ6品（東坡肉、西湖醋魚、龍井蝦仁ほか）
- 龍井茶の解説と「四絶」紹介
- アクセス情報とベストシーズン

## 起動方法

依存ゼロの静的サイトです。ローカルで開くには：

```bash
# ブラウザで直接開く
open index.html

# または簡易サーバーで
python3 -m http.server 8000
# → http://localhost:8000
```
