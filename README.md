# GitHub はじめの一歩

GitHub初心者向けの、学習チェックリストWebアプリです。名前を入力して学習カードを作り、GitHubの基本用語を読みながら、できた項目にチェックを入れられます。

## できること

- 名前（ニックネーム）入りの学習カードを作成
- リポジトリ、コミット、ブランチ、プルリクエストをやさしい日本語で説明
- 学習チェックリストと進捗（しんちょく）バーを表示
- 進み具合と名前を `localStorage`（ブラウザにデータを保存する仕組み）へ保存
- スマートフォンでも読みやすい画面

## 使い方

1. `index.html` をブラウザで開きます。
2. 名前を入力して「カードを作る」を押します。
3. 学んだ項目にチェックを入れます。

サーバーや追加のライブラリ（便利な機能をまとめた外部ファイル）は必要ありません。GitHub上で公開する場合は、リポジトリへ3つのファイルをアップロードし、GitHub Pages（リポジトリの内容をWebサイトとして公開する機能）を設定します。

## ファイル構成

```text
.
├── index.html  # 画面の内容（HTML：Webページの骨組み）
├── styles.css  # 見た目（CSS：色や大きさのルール）
└── app.js      # 動き（JavaScript：クリックなどに反応するプログラム）
```

## 初心者向けメモ

- **HTML**：見出し、文章、ボタンなど「何を表示するか」を書きます。
- **CSS**：色、余白、並び方など「どう見せるか」を書きます。
- **JavaScript**：チェックしたときの表示変更や保存など「どう動かすか」を書きます。
